## 3. 内容模块的分类口径(执行者按此分,不自由发挥)

判据全部在模板表 `carve-rules-provisional/schema/*.json` 的 `roles` 里,**按 sortOrder 先具体后一般,首次命中即止**。
下面只列**容易判错的**几条与它们的理由:

| 形态 | 判成什么 | 为什么(都是踩过的坑) |
|---|---|---|
| `（1）实验采用的科学方法是＿（选填"A．控制变量法"或"B．等效替代法"）` | **小问**,不是选项行 | 小问/圈号项的 sortOrder 必须**排在选项行之前**;否则行内选填的两个标号会让整条小问被拆成两个假选项而销毁 |
| `0.04s×3=0.12s故B符合题意` | **正文**,不是编号项 | 编号项判据:全角 `．、` 一律题号;半角 `.` 需其后有空白或紧跟非数字。否则小数被当题号,凭空多出一道题 |
| `4．2025年我国在航空领域…` | **编号项** | 全角句点直接接年份,是真题干。收紧判据时不可误伤 |
| 【详解】之后的 `A．量角器是…故A不符合题意；` | **解析**,不是选项 | 标签激活期间一切归标签。形状与选项行完全相同,只能靠上下文判 |
| `分析：` / `解：` / `答：` 开头 | **教科书体例的解析/答案** | 全册 11 处。必须做成 role(逐段锚定),不能做成 tag——`分析：` 段中另有 10 处(小问里的「（1）分析：」),`答：` 段中 2 处(其中一处是填空 `答：______`) |
| 第01讲(序言)下的小标题 | **不建知识点** | PM 裁定:序言是导学,大纲层照常登记,不进知识点体系 |

## 4. 标签口径

- **知识点**:真源 = 深研精炼的「知识点NN xxx」,概念构建的「一、xxx」降为别名。
  显示名以 `manifests/2026-08-20-physics-g08-summer-knowledge-roster.json` 为准(53 条,有效 50 条,含 6 条措辞裁决)。
  **不得自造名**;写 `concepts` 前先按归一化名查重。
- **题型**:**以源为准,没有就不记**。
  - 讲义:分组标题「一、单选题」等(只有 10/20 讲有)
  - 单元卷:卷首『考生注意』声明的默认值(未标注=单选,**只覆盖选择题**)+ 行内「（多选）」
  - 讲义:行内「（多选题）」(实测 4 处)
  - 平台若因数据模型需要而推断,**必须另记「题型来源」**,让"源没说"这件事看得见。
- **难度**:源里**没有**。13 种形态全量扫过,逐题难度标记 0 处。**不许推断。**

## 5. 排版布局(非内容信息)记到什么程度

**记到能还原为止。** 判准不是字段清单,是 A13。

做法:非内容层 `work/layout.json`(`s4c5-capture-layout`),与内容层**分开存**。
逐字捕获 `pPr` / `rPr` / 图形锚定与环绕 / 表格三层属性 / 分节属性,按 locator 归位。
**不枚举字段**——照着清单逐个补,下一份源换一批事实又得重来;逐字捕获则新事实自动被记下。

实测:讲义 5351 块 / 55 类事实;单元卷 895 块 / 39 类。

★**文档标识统一用 registry 的 `lesson`**(`第A01讲`),不用分档文件名(`A01-序言-…`)。
两层各用各的键,对账时必然全对不上。
